## Case 1: 전역 llm-wiki 셤이 옛 무스코프 이름의 npm link 접션이었다

### Grounding
- Git Context: `hash:5cf6219`
- Evidence: `C:\Users\admin\AppData\Roaming\npm\node_modules\llm-wiki` (JUNCTION → D:\Project\llm-wiki, 2026-08-29 생성), `npm ls -g @kybird/llm-wiki` = empty
- Confidence: 5/5

### Discovery
`which llm-wiki`가 가리킨 셤은 `node_modules/llm-wiki/bin/llm-wiki.js`를 실행했다 — 스코프 전환 **이전 이름**으로
npm link가 걸려 있었다(8/29, 패키지명이 `@kybird/llm-wiki`가 되기 전). 접션이 이 레포 작업 트리를 직접 가리키므로
동작은 최신 코드 그대로였지만, `npm ls -g @kybird/llm-wiki`는 비어 있고 `npm update -g llm-wiki`를 돌리면
**타인이 선점한 npm의 남의 패키지**를 끌어와 접션을 덮어쓰는 사고가 난다.

### Analysis
- Why non-obvious: 커맨드가 "잘 되니까" 아무도 점검하지 않는다. `npm ls -g`에 안 잡히는 옛 이름 링크는
  업데이트 경로에서만 폭발한다 — 조용한 지뢰.
- Impact: README의 Updating 절차(`npm update -g llm-wiki`)가 이 머신에선 오히려 파괴적으로 해석될 수 있었다.
- Action taken: `npm uninstall -g llm-wiki` 후 이 레포에서 `npm link` 재실행 → `node_modules/@kybird/llm-wiki`
  접션 + 셤 재생성, 검색 동작 재확인(시맨틱 91% 히트).

## Case 2: qmd 글로벌 설치 = 머신 전체 시맨틱 활성화, "No semantic results" 3단 진단

### Grounding
- Git Context: `hash:5cf6219`
- Evidence: `npm i -g @tobilu/qmd` (158패키지, 프리빌트 경로 무사) → `llm-wiki compile index` 로그
  (컬렉션 llm-wiki-wiki/-raw 생성, embeddinggemma-300M-Q8_0.gguf, 12문서 25청크 4초), 검색 실측 91~94%
- Confidence: 5/5

### Discovery
`findQmd()`가 `npm root -g`를 보므로 **qmd 글로벌 설치 한 번으로 이 머신의 모든 레포가 자동 인식**한다 —
레포별 설치 불필요. 단 시맨틱 결과를 내려면 그 레포에서 `llm-wiki compile index` 1회로 컬렉션 색인+임베딩이
선행되어야 한다(컬렉션은 전역 ~/.config/qmd에 프로젝트별 고유 이름).

"No semantic results"가 나왔을 때의 실제 원인 분기(순서대로 확인):
1. 임베딩이 아직 없다(compile index 전) — 이 세션에서도 색인 전 질의는 전부 빈 결과였다.
2. 질의 주제가 색인 코퍼스(doc/wiki+doc/raw)에 없다 — README 내용을 물어도 wiki엔 없다.
3. 유사도가 qmd 임계값 미달 — 먼 설명투/교차언어 질의("패키지를 공개했는데 찾을 수 없음" 등)는 빈 결과.
   버베이티·별칭에 가까운 질의("검색 교차 오염", "스코프 배포")는 91~94%로 정확히 명중.

### Analysis
- Why non-obvious: 빈 결과가 "고장"과 "정상 한계"를 구분 못 준다 — grep은 항상 병렬로 돌아 실패를 가려준다.
- Impact: [[always-merge-exact-matching]]의 실측 보강 — 시맨틱은 동의어 질의에서만 우월하고
  재현율은 grep이 담보한다.
- Action taken: TTSTextReader(ttswiki 컬렉션 573+122문서)도 다음 그 레포의 compile index 1회로 시맨틱 합류.
  qmd 미사용 시절 청크 5022개 고아 벡터(62%) — `qmd cleanup`으로 회수 가능(보류).
