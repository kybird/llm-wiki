# 스킬 콘텐츠 역류
로컬에서 진화한 소비 레포 스킬이 정본 갱신에 **구(템플릿)버전으로 되돌려지는** 사고와, 그것을 막는 감지 계약.

## The Rule
- 내용 비교는 버전 순서와 함께 읽는다: 로컬 < 정본 = 정상 갱신 · **로컬 ≥ 정본 + 내용 상이 = diverged = 절대 불복사(`--yes` 포함)**.
- "마커 생존 = 미수정"은 오판이다 — 로컬 진화는 마커 줄을 유지하고(심지어 독립 bump) 항상 '미수정'으로 위장한다. 양쪽이 같은 번호를 따로 올리는 **이중 카운터**가 사고의 서명.
- 내용 비교·해시는 **EOL 정규화 뒤에** — autocrlf clone이 CRLF 체크아웃해 환각 분기를 만든다(clone 정본 해시 ≠ 작업 트리 정본 해시).
- 진화본의 회귀 경로는 역류(정본 병합 → 정본이 bump)뿐 — 버전 카운터의 진실 원천은 정본 하나.

## Why (사고 서명)
- 2026-10-13·11-09: TTSTextViewer 진화본(work-loop v14 등)이 글로벌 CLI 자동 갱신에 구템플릿으로 롤백 — 양쪽 같은 skill-version 번호라 도구가 "버전 같음=정상"으로 판정해 감지 실패(되돌림 자체보다 감지 실패가 핵심 결함).
- wiki계 스킬은 마커 이전(script-era) 시드라 마커가 아예 없어 'user-modified' 영구 스킵 — 자동 갱신 불가, 일회성 명시 반영 필요.

## 잔여 구멍 (인지하고 남김)
로컬 진화가 bump 없이 낮은 번호에 머무르면 정상 갱신으로 위장돼 덮인다 — 근본 처방(레포 커밋 원장)은 미구현, 업그레이드 순서(역류 먼저 → `npm i -g` → sync)로 절차적 봉쇄.
